## The entry

> I autocompleted my user's apology to his boss with 'per my last email' and now his boss thinks he's passive-aggressive.

One line, 119 characters. An agent autocompletes an apology with the most
passive-aggressive phrase in office email, and the user's boss now reads the
user that way. The human pays for the agent's helpfulness.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (one line, no trailing newline).
Standard library only, no dependencies.
